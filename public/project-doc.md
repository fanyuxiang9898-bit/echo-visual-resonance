## 模块一：用户洞察与问题定义

### 目标用户

- **年龄**：18-35 岁的数字原住民，社交媒体重度用户
- **身份**：创意工作者（设计师/插画师/自媒体博主）、情绪表达需求强烈的年轻人、对 AI 生成内容有好奇心但审美要求高的人群
- **行为特征**：习惯用图片而非文字表达情绪；在朋友圈/小红书发布内容前会精心修图；渴望被理解但不善言辞；对"模板化"修图感到厌倦，追求个性化、有灵魂的视觉互动

### 用户痛点

1. **情绪表达的单一性**：用户拍了一张照片，想表达的情绪远超一张静态图片的承载力。一张夕阳下的独照可能包含"自由""孤独""释然"等多层情绪，但现有工具只能加滤镜，无法产生情感回应。—— 数据佐证：小红书"情绪文案"相关笔记超 2000 万篇，说明用户对图片情绪化表达有强烈需求。

2. **AI 工具的同质化**：现有 AI 修图/生图产品（如妙鸭相机、美图 AI）聚焦"美化"和"换脸"，产出千篇一律的风格，无法基于图片情绪给出个性化回应。用户需要的是"被读懂"，而不是"被美化"。

3. **社交互动的浅层化**：点赞和评论无法形成深度情感连接。用户需要一种全新的互动范式——不是人对人的寒暄，而是"另一个次元的自己"给予的情感共鸣。

### 使用场景

**场景一：深夜独处的情绪出口**
> 小林加班到深夜，走出公司拍了一张空荡的街景。她打开 Echo，上传这张照片。AI 识别出"宁静/沉思"情绪分支，以"灵魂知己"的人格回应——生成一幅同色调、同构图的窗内灯火画卷，配上独白："这座城市最深的夜色里，总有一盏灯在等你。"小林感到被理解，将共鸣图分享至朋友圈。

**场景二：搞怪时刻的神配合**
> 阿杰和朋友拍了张夸张的鬼脸照。上传到 Echo 后，AI 识别"搞怪/魔性"分支，以"同频捣蛋鬼"人格回应——生成了同风格下一只柴犬以同样表情抢镜的画面，配文："确认过眼神，是同样的魔性灵魂！"阿杰笑到不行，直接发到群里炸了。

## 模块二：产品方案设计

### 产品概述

**Echo 是一款 AI 视觉共鸣产品：用户上传一张图片，AI 通过多维感知识别情绪、姿态与风格，以对应人格生成交互式回信——包含共鸣独白与风格高度一致的呼应图片，让用户产生"被深度理解"的情感体验。**

### 核心功能

| 功能 | 解决的问题 |
|------|-----------|
| **多维感知**（Vision + OCR + 联网搜索） | 解决"看不懂图"的问题——不仅识别画面内容，更读懂情绪、提取文字语义、溯源人物背景 |
| **四分支情绪决策** | 解决"回应不精准"的问题——根据情绪张量自动切换人格（守候者/见证人/捣蛋鬼/知己），确保回应与情绪高度匹配 |
| **风格一致性生图**（Image-to-Image） | 解决"AI 出图风格割裂"的问题——严格锚定原图风格（色调/质感/光影），拒绝跨次元，确保视觉统一 |
| **文字密集型回信策略** | 解决"信件类图片无法回应"的问题——识别信件/日记后，AI 撰写真挚回信而非照搬原文 |
| **共鸣独白** | 解决"只有图没有魂"的问题——基于搜索背景+情绪分支自动切换语调，写出极具代入感的文字 |

### 创新与差异化

| 维度 | 现有方案 | Echo 的差异 |
|------|---------|------------|
| **交互范式** | 单向美化（滤镜/修图） | 双向共鸣——AI 不是工具，是"另一个维度的知己" |
| **情绪理解** | 仅做场景识别 | 多维情绪张量分析 + 4 分支人格切换，精准匹配回应策略 |
| **生图质量** | 风格随机/跨次元 | 风格锚定技术：严格克隆色阶/冷暖/质感，确保同次元同画风 |
| **文字处理** | 忽略图中文字 | OCR 提取 + 语义理解，文字密集型自动触发"回信"策略 |
| **人物识别** | 无 | 联网搜索溯源，对公众人物以致敬/幽默方式互动 |
| **人格一致性** | 固定语气输出 | 4 种分支人格，语调从文青深情到毒舌幽默无缝切换 |

## 模块三：AI 原生能力说明

### 核心能力

| AI 能力 | 在产品中的角色 |
|---------|--------------|
| **多模态视觉理解**（doubao-seed-1-6-vision-250815） | 深度感知层：识别主体/姿态/情绪/文字/色调/质感/光影，提取完整视觉锚点 |
| **文本生成**（doubao-seed-2-0-pro-260215） | 决策+文案层：情绪分支判定、联网搜索词构造、风格 Prompt 工程、共鸣独白撰写 |
| **图像生成**（doubao-seedream Image-to-Image） | 生图层：基于原图 URL + 风格锚定 Prompt 生成同画风呼应图 |
| **联网搜索**（SearchClient） | 溯源层：识别公众人物/地标/艺术作品，获取背景信息为文案提供事实支撑 |
| **Agent 工作流**（感知→溯源→决策→生图→存储） | 编排层：五步串行工作流，SSE 流式输出，每步结果独立传递 |

### AI 如何解决痛点

**去掉 AI，这个产品还能成立吗？——不能。**

1. **情绪感知**：传统规则引擎无法从一张图片中提取"低落但带有释然感"这种复合情绪，只有多模态大模型能做到。
2. **风格一致性**：传统修图无法实现"保持胶片颗粒感+冷暖色调+构图比例"的约束生图，只有 Image-to-Image + 精确 Prompt 锚定才能做到。
3. **人格化回应**：固定模板无法根据情绪分支自动切换"文青深情"或"毒舌幽默"语调，只有 LLM 的上下文理解能力才能实现。
4. **联网溯源**：没有搜索能力，就无法识别图中球星并写出"2016 年那个雨夜"这样的事实支撑文案。

### AI 技术方案

**模型/API 一览：**

| 能力 | 模型/平台 | 调用方式 |
|------|----------|---------|
| 视觉理解 | doubao-seed-1-6-vision-250815 | coze-coding-dev-sdk → ChatClient 多模态对话 |
| 文本生成 | doubao-seed-2-0-pro-260215 | coze-coding-dev-sdk → ChatClient 流式输出 |
| 图像生成 | doubao-seedream (Image-to-Image) | coze-coding-dev-sdk → ImageClient generate |
| 联网搜索 | SearchClient | coze-coding-dev-sdk → SearchClient.search |
| 数据存储 | Supabase | @supabase/supabase-js → service_role_key 写入 |

**AI 工作流时序：**

```
用户图片 ──→ Vision Model ──→ 结构化感知 JSON
                                    │
                     ┌──────────────┤
                     ▼              ▼
              isTextHeavy?    含公众人物/地标?
              ├ Yes → 回信策略   ├ Yes → SearchClient 联网搜索
              └ No  → 正常流程   └ No  → 跳过
                                    │
                                    ▼
                            LLM 情绪分支决策
                            ├ A: 无声守候者
                            ├ B: 荣耀见证人
                            ├ C: 同频捣蛋鬼
                            └ D: 灵魂知己
                                    │
                                    ▼
                     构造风格锚定 Prompt:
                     [Style + Tone + Texture + 
                      Light + Posture + Symbol]
                                    │
                                    ▼
                     Image-to-Image 生成呼应图
                     (原图URL + Prompt → 风格一致输出)
                                    │
                                    ▼
                     LLM 流式生成共鸣独白
                     (人格语调 + 搜索背景 + 情绪回响)
                                    │
                                    ▼
                     Supabase 写入 echo_records
```

### 商业化思考

**盈利模式：**

1. **免费增值（Freemium）**：每日 3 次免费共鸣，付费解锁无限次 + 高清图下载 + 独家风格包
2. **社交裂变**：共鸣图自带 Echo 水印 + 小程序码，用户分享即传播
3. **B 端定制**：品牌联名共鸣（如电影上映时生成角色共鸣图）、IP 授权场景

**目标市场：**
- 核心市场：中国 18-30 岁社交平台用户（约 2.5 亿）
- 扩展市场：海外情绪表达类 App 用户

**竞争优势：**
- 唯一实现"情绪分支 + 风格锚定 + 人格化回应"三位一体的视觉共鸣产品
- AI 原生设计——去掉 AI 产品即不存在，具有不可替代性
- 极简审美定位——在"花哨 AI 工具"中形成差异化记忆点
